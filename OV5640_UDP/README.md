# OV5640_UDP

该项目是 OV5640 采集图像，通过以太网传输 UDP 包，最后在 PC 端上位机显示。

## 实现原理

工程上电后，先通过 `ov5640_top` 对 OV5640 进行初始化配置，使摄像头输出 1280x720 的 RGB565 图像数据。

图像数据采集后按行打包发送。每个 UDP 包对应一行图像数据，payload 前 2 个字节是行号，后面是该行的 RGB565 像素数据。以 1280x720 为例，每行数据长度为 `2 + 1280 * 2 = 2562` 字节。PC 端上位机收到数据后，根据行号把每一行放到对应位置，最后拼成完整图像。

由于摄像头像素时钟和 GMII 发送时钟不同，工程中使用 `eth_tx_fifo` 做跨时钟缓存。当 FIFO 中缓存够一行图像后，`eth_tx_ctrl` 触发 `eth_udp_tx_gmii` 发送一次 UDP 包，模块会自动补上以太网头、IP 头、UDP 头和 CRC，最后通过 GMII 接口发送到网口。

工程中配置的网络参数如下：

| 参数 | 值 |
| --- | --- |
| 目的 MAC | `C8_A3_62_E2_75_5E` |
| 源 MAC | `00_0A_35_01_FE_C0` |
| 目的 IP | `192.168.0.3` |
| 源 IP | `192.168.0.2` |
| 目的端口 | `6102` |
| 源端口 | `5000` |

电脑端配置可以参照 Word 文档，上位机也给你们放上了，你也可以自己让 AI 写一个上位机。
