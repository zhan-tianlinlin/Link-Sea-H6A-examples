# GMII_UDP_lookback

该项目实现以太网 UDP GMII 回环。

代码借鉴于小梅哥。使用前建议先阅读项目中的 PDF 文档，将电脑绑定到对应的 IP；另一个工具是用于发送数据包并进行回环测试的上位机。

具体用法可以去看 B 站上小梅哥的视频。

## 遇见的问题！！！
