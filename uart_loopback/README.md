# 串口回环例程

## 功能

该项目实现 UART 串口回环：上位机通过串口发送数据到 FPGA，FPGA 接收后再通过串口发送模块原样发回，用来验证串口发送和接收模块是否正常工作。

你们可以拿里面的发送和接收模块去干别的事
