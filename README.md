# OV5640 HDMI 640x480 FPGA 例程

## 例程内容

本例程包括以下模块：

- OV5640 初始化模块
- SIL9134 初始化模块（HDMI 输出配置）
- SDRAM 存储控制模块
- VGA 时序输出模块

整体视频处理流程为：OV5640 摄像头采集图像，经 SDRAM 缓存后，由视频时序模块输出至 HDMI 显示设备。

## 开发过程中遇到的问题

一个比较奇怪的问题是：SDRAM 读端口的时钟不能与 HDMI 输出时钟使用同一个时钟，否则显示屏不会显示画面。

但是，当顶层输出端口增加 `sdram2` 后，SDRAM 读端口与 HDMI 输出端口使用同一个时钟，完成布线后却可以正常显示。推测这是由于布线变化引起了时序变化。

## 解决方法

由于本例程只使用了 `sdram1`，因此将 SDRAM 读端口时钟 `clk_sdram_rd` 的频率设置为与 HDMI 输出时钟 `hdmi_out_clk` 相同，但让两个时钟保持不同相位：

- `clk_sdram_rd`：相位 90°
- `hdmi_out_clk`：相位 270°

采用该方式后，视频可以正常显示。
